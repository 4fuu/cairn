# Cairn v2026.1127.3

## Highlights

- Added `cairn version` with a cached release check and an update notice at most once every 24 hours.
- Added `--format text|json` and `--detail` so default output stays compact and actionable without forcing extra round trips.
- Renamed the skill to `cairn-session-search`; install it with `npx skills`.

## Changes

- `cairn search` keeps the best message UUID in the default grouped output, so `show --around <uuid>` can follow directly. Scores, sequence numbers, roles, and content types move behind `--detail`.
- `cairn show` returns visible text by default. `--tools` adds tool calls/results; `--detail` adds UUID, model, token counts, and meta flags.
- `--include-meta` and `--tools` still control which rows are selected; `--detail` only adds fields.
- Update notices go to stderr and never corrupt JSON. The state is stored in `~/.cairn/update-check.json` (or `$CAIRN_HOME/update-check.json`).
- Disable checks with `--no-update-check` or `CAIRN_NO_UPDATE_CHECK=1`.
- Fixed the broken-pipe panic when piping text output, such as `cairn sources | head`.
- Added a performance section to the README, split detailed documentation into `docs/`, and added `AGENTS.md` plus CI.

## Fixes

- Avoided a panic when a downstream pipe closes early.
- Avoided an update notice on every command by caching the check for 24 hours.

## Upgrade notes

- Reinstall the skill with the new name:


- Scripts that relied on the old verbose JSON shape should add `--detail`; the default shape is now compact.
