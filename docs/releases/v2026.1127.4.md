# Cairn v2026.1127.4

## Highlights

- Added `--type` to `search` and `show` for selecting specific content types.
- Added `--tool` to select calls and results for a specific tool.

## Changes

- `--type` accepts `text`, `thinking`, `tool_use`, `tool_result`, `tool`, `bash`, `summary`, and other stored content types. It is repeatable.
- `--type tool` expands to both `tool_use` and `tool_result`.
- `--tool NAME` is case-insensitive and keeps both the tool call and its result.
- These filters select rows directly; they do not require `--include-meta` and do not change the fields added by `--detail`.

## Examples

```sh
cairn search "callback" --type tool_result
cairn search "timeout" --tool bash --all
cairn show <session-id> --type thinking
cairn show <session-id> --tool read
```

- No index migration is required.
- Existing commands keep their previous behavior.
