# Cairn v2026.1127.5

## Highlights

- `--type` and `--tool` now accept comma-separated multi-select values as well as repeated flags.

## Changes

- `--type tool_use,bash` selects both content types in one argument.
- `--type tool_use --type bash` continues to work.
- `--tool read,shell` selects calls and results for both tools.
- Tool names remain case-insensitive, and `--type tool` still expands to `tool_use` and `tool_result`.

## Examples

```sh
cairn search "callback" --type tool_use,bash
cairn search "timeout" --tool bash,read --all
cairn show <session-id> --type tool_use,bash
cairn show <session-id> --tool read,shell
```

## Upgrade notes

- No index migration is required.
- Existing single-value and repeated-flag commands are unchanged.
